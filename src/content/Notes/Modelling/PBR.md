# PBR: 基于物理的渲染


PBR 的核心目标是通过**模拟光线在真实世界中的物理行为**，来生成更**逼真、更一致、更可预测**的渲染图像。它摒弃了传统经验式光照模型（如 Phong, Blinn-Phong）中大量依赖“艺术感觉”和“手动调整”的魔法参数，转而使用**基于真实物理测量的材质属性**和**遵循物理定律的光照计算**。

**为什么需要 PBR？**

1. **传统模型的局限性：** 像 Phong 模型使用“环境光”、“漫反射”、“高光反射”等分离的、人为定义的参数。调整这些参数来模拟不同材质（如金属、塑料、木头）非常依赖艺术家的经验，并且在不同光照环境下（如日光灯 vs 白炽灯）效果可能不一致，甚至出错（例如违反能量守恒）。
    
2. **追求真实感：** 随着硬件性能提升，用户对图形真实感的要求越来越高。PBR 通过更准确地模拟光与物质的相互作用，提供了更高层次的视觉保真度。
    
3. **工作流程标准化：** PBR 定义了一套相对标准化的材质参数（如金属度、粗糙度），使得艺术家更容易创建在各种光照条件下都能表现正确的材质，也方便不同软件和引擎之间交换资源。
    

**PBR 的基石原则：**

1. **微表面理论 (Microfacet Theory):**
    
    - 这是 PBR 描述表面反射的核心模型。
        
    - 它认为，看似光滑的宏观表面，在**微观尺度**上其实是由无数微小的、朝向各异的“镜面”小平面（微表面）组成的。
        
    - **表面粗糙度 (Roughness)** 或 **光滑度 (Smoothness)** 参数本质上描述了这些微表面法线方向的**统计分布**（通常用 Beckmann 或 GGX 分布函数建模）。
        
        - **粗糙度低（光滑）：** 微表面法线高度一致 -> 反射光集中 -> 清晰锐利的高光。
            
        - **粗糙度高（粗糙）：** 微表面法线非常分散 -> 反射光发散 -> 模糊柔和的高光。
            
    - 这个理论完美地将漫反射和镜面反射统一在同一个物理框架下：粗糙表面上的镜面反射会因微表面的遮挡和相互反射而扩散开，形成视觉上的“漫反射”效果（尽管本质仍是无数微小镜面反射的统计结果）。
        
2. **能量守恒 (Energy Conservation):**
    
    - 这是物理学的基本定律：**入射光线的总能量必须等于出射光线的总能量（反射光 + 折射/透射光 + 被吸收的能量）**。
        
    - 在 PBR 中严格遵守这一原则：
        
        - 反射光（镜面反射）的**亮度不能超过**入射光的亮度。
            
        - **反射光（镜面）和折射/透射光（漫反射/次表面散射）是互斥的**。对于一个特定的光线路径，能量不能同时出现在反射和折射部分。
            
        - **金属材质：** 几乎所有的折射光都会被自由电子立即吸收（转化为热量），因此金属**几乎没有漫反射**（除了氧化层或涂层），其颜色主要来自**有色的镜面反射**（菲涅尔效应）。金属吸收的能量高。
            
        - **非金属材质（电介质）：** 如塑料、木头、陶瓷、皮肤等，它们既有反射也有折射。折射光进入内部后，一部分被吸收（决定漫反射颜色），一部分可能通过次表面散射再次射出（形成漫反射）。吸收的能量相对较低。
            
    - 能量守恒确保了材质在不同光照强度下表现自然，避免出现过曝或不合理的亮度。
        
3. **菲涅尔效应 (Fresnel Effect):**
    
    - 描述**反射率随观察角度变化的物理现象**。
        
    - 关键点：
        
        - 当光线以**掠射角**（几乎平行于表面）观察时，**任何材质**的反射率都**接近 100%**（像镜子一样）。
            
        - 当光线以**垂直角度**（法线方向）观察表面时，反射率最低（由材质的**基础反射率**决定）。
            
        - **非金属：** 基础反射率很低（通常 2%-5%），且基本**无色**（RGB值接近相同，例如 `0.04`）。随着角度增大，反射率显著增加至接近白色。
            
        - **金属：** 基础反射率很高（通常 70%-100%），并且反射光**带有颜色**（这是金属呈现颜色的主要方式）。随着角度增大，反射率也增加。
            
    - PBR 材质通过 `F0`（0度角的基础反射率）参数来体现菲涅尔效应。
        
        - 非金属的 `F0` 通常是一个很小的标量值或接近 `0.04` 的灰度值。
            
        - 金属的 `F0` 是其 RGB 色彩值（如金是黄色 `(1.0, 0.71, 0.29)`，铜是红色 `(0.95, 0.64, 0.54)`）。
            
    - **金属度 (Metallic)** 参数：这是一个介于 `0`（纯非金属）和 `1`（纯金属）之间的值。它的核心作用是**混合/切换**材质的 `F0` 和漫反射行为：
        
        - `Metallic = 0`：使用默认的非金属 `F0`（如 `0.04`），并启用**漫反射颜色**。
            
        - `Metallic = 1`：使用**指定的 `F0` 作为基础反射率**（通常是彩色），并**禁用漫反射颜色**（或将其设为黑色）。
            
        - `Metallic = 0.5`：在 `0.04` 和指定的 `F0` 之间插值作为基础反射率，同时减弱漫反射。
            

**PBR 的核心材质参数：**

1. **基础色 (Albedo / Base Color):**
    
    - 定义材质在**纯白、均匀漫射光照**下呈现的**固有颜色**。
        
    - 对于**非金属**：这是材质的**漫反射颜色**（即折射光进入材质后被选择性吸收后返回的颜色）。
        
    - 对于**金属**：这个参数**不表示漫反射**（金属几乎没有漫反射），而是用于指定其**有色的基础反射率 `F0`**。
        
    - **重要：** 基础色纹理**不应包含光照信息**（如阴影、高光），只包含材质本身的颜色属性。通常是一张 sRGB 空间的颜色纹理。
        
2. **金属度 (Metallic):**
    
    - 一个单通道（灰度）的值或纹理（`0.0 - 1.0`）。
        
    - 如前所述，它控制材质是更像金属（`1`）还是更像非金属（`0`），并据此切换 `F0` 和漫反射行为。介于中间的值表示类似生锈金属、上漆金属等混合材质。
        
3. **粗糙度 (Roughness):**
    
    - 一个单通道（灰度）的值或纹理（`0.0 - 1.0`）。
        
    - 控制微观表面的不规则程度。
        
    - `0`：完美光滑 -> 清晰锐利的镜面反射。
        
    - `1`：极度粗糙 -> 模糊、扩散的镜面反射（接近漫反射外观）。
        
    - 它直接影响镜面高光的“聚焦”程度。
        
4. **法线贴图 (Normal Map):**
    
    - 虽然不是 PBR 独有的，但在 PBR 工作流中至关重要。
        
    - 它通过 RGB 值（代表切线空间中的 XYZ 方向偏移）来模拟表面微观几何细节（凹凸、划痕、纹路），**不改变模型的真实几何**。
        
    - 这些微观细节会极大地影响微表面法线分布，从而影响高光的形状和分布，增强真实感。
        
5. **环境光遮蔽贴图 (Ambient Occlusion Map - AO Map):**
    
    - 一个单通道（灰度）纹理。
        
    - 预计算或烘焙的贴图，用于模拟模型自身几何结构在**缝隙、褶皱、凹陷**处产生的**阴影和遮蔽**效果，使得这些区域接收的环境光更少。
        
    - 通常**在最后阶段与其他光照结果相乘**，增加细节和深度感。它不属于核心物理参数，但能显著提升最终效果。
        

**可选/高级参数：**

- **高度图/视差贴图 (Height Map / Parallax Map):** 提供更真实的深度感（视差效果）。
    
- **细节遮罩 (Detail Mask):** 控制细节纹理（如法线、粗糙度）的应用区域。
    
- **次表面散射 (Subsurface Scattering):** 对于皮肤、玉石、蜡等半透明材质，需要额外的参数（散射颜色、散射强度、散射距离）来模拟光线在材质内部的传播。
    
- **各向异性 (Anisotropy):** 模拟表面具有方向性微结构（如拉丝金属、头发、CD 表面）导致的高光变形（椭圆形或拉伸）。
    
- **清漆层 (Clear Coat):** 模拟在基础材质上覆盖一层透明清漆（如车漆、木器漆），具有独立的菲涅尔、粗糙度等属性。
    
- **发射光 (Emission):** 使材质自发光。
    

**PBR 工作流程：**

1. **材质定义：** 艺术家使用 PBR 材质编辑器（如 Substance Painter, Blender, Unity URP/HDRP, Unreal Engine Material Editor）设置或绘制 `Albedo`, `Metallic`, `Roughness`, `Normal` 等纹理/参数。
    
2. **光照环境：** 使用基于物理的光源（通常强度以物理单位如坎德拉 `cd` 或流明 `lm` 定义）和**基于物理的图像照明 (HDRI / Image-Based Lighting - IBL)**。IBL 使用全景高动态范围环境贴图（HDRI）来捕获真实世界的复杂光照信息，提供精确的环境光和反射。
    
3. **渲染计算：** 渲染引擎（如 Unity, Unreal Engine, V-Ray, Arnold）使用 PBR 着色器（如 Cook-Torrance BRDF）和物理正确的光照方程进行计算。核心计算包括：
    
    - 基于 `Metallic` 和 `Albedo` 确定 `F0`。
        
    - 基于 `Roughness` 和微表面分布函数计算法线分布项、几何遮蔽项。
        
    - 基于菲涅尔方程计算菲涅尔项。
        
    - 结合所有 BRDF 项计算镜面反射。
        
    - 基于 `Metallic` 和能量守恒计算漫反射。
        
    - 应用法线贴图扰动微表面法线。
        
    - 结合环境光（来自 IBL）和直接光照。
        
4. **后处理：** 可能应用色调映射（将 HDR 转为 LDR 显示）、抗锯齿、环境光遮蔽（SSAO 或使用 AO Map）、辉光等效果。
