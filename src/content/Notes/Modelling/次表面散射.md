# 次表面散射
次表面散射是一种物理光学现象，指的是当光线照射到**半透明或浑浊**的材质表面时，光线**不会立即在入射点完全反射或吸收**，而是**穿透进入材质内部**，在内部经过**多次散射、吸收、折射和反射**之后，最终从**入射点周围的不同位置**重新射出材质表面的过程

传统的光照模型（如经典的漫反射和镜面反射模型）主要处理光线在**物体表面**的反射行为。这对于金属、光滑塑料等不透明材质效果很好。但对于许多常见的、看起来有生命感或特殊质感的材质，仅靠表面反射模型会显得**非常假、像塑料**

1. **光线入射与折射 (Incident Light & Refraction):**
    
    - 光线照射到材质表面。
        
    - 根据斯涅尔定律 (Snell's Law)，一部分光线在表面发生**镜面反射** (Specular Reflection)，这是我们看到的高光。
        
    - 另一部分光线**折射**进入材质内部。这是次表面散射过程的**起点**。折射的程度取决于材质的折射率。
        
2. **光线在介质内部传播 (Light Propagation in Medium):**
    
    - 一旦进入材质内部，光线就进入了一个充满**微小粒子**（如皮肤细胞、大理石中的晶体、牛奶中的脂肪球、蜡中的分子团、纸张中的纤维等）和**非均匀结构**的环境。
        
    - 光线在内部传播时，主要与这些微观结构发生两种相互作用：
        
        - **吸收 (Absorption):** 光线（或者说光子）的能量被材质中的分子或色素吸收，转化为热能。**不同波长的光被吸收的程度不同**（选择性吸收）。例如：
            
            - 皮肤下的血红蛋白强烈吸收蓝光和绿光，但允许更多的红光通过。
                
            - 树叶中的叶绿素吸收红光和蓝光进行光合作用，反射绿光。
                
            - 玉石中的杂质吸收特定波长的光，呈现其独特的颜色。
                
        - **散射 (Scattering):** 光线遇到微观粒子或密度/折射率不均匀的区域时，其传播方向会发生改变（偏转）。散射可以是：
            
            - **各向同性散射 (Isotropic Scattering):** 光线向所有方向散射的概率相等（像一个完美的漫反射点）。
                
            - **各向异性散射 (Anisotropic Scattering):** 光线更倾向于朝某些特定方向散射。在次表面散射中，**前向散射 (Forward Scattering)** 通常占主导，即光线方向改变不大，继续大致沿原方向前进（例如在皮肤、牛奶中）。**后向散射 (Backward Scattering)** 则指光线被反弹回入射方向附近（在某些浑浊材质中更明显）。
                
            - 散射的强度和方向性由材质的微观结构决定，并通常用**散射相位函数 (Scattering Phase Function)** 来描述。
                
3. **多次散射事件 (Multiple Scattering Events):**
    
    - 关键点在于：进入材质的光线**极少只经历一次散射事件就射出**。
        
    - 光线会在材质内部经历**多次**、**随机**的**吸收和散射**事件。每次散射都改变光线的方向，每次吸收都减弱其强度并可能改变其颜色（波长组成）。
        
    - 这个随机的“弹珠游戏”过程导致光线在材质内部**扩散**开来。
        
4. **光线重新射出 (Light Exit):**
    
    - 经过内部的一系列散射和吸收后，残余的光线最终会再次到达材质表面。
        
    - 在表面，根据斯涅尔定律，这部分光线再次发生折射，**射出**材质，进入我们的眼睛或相机。
        
    - **核心原理体现：** 光线**重新射出的位置**通常**远离**其**最初入射的位置**。这个偏移的距离是次表面散射最显著的特征，也是它与传统表面反射（光线在入射点附近反射）的根本区别。
        
    - 出射点的分布和出射光线的强度、颜色，由光线在材质内部走过的**路径**、经历的**散射次数和方向**以及**吸收量**共同决定。
        

**关键物理参数：**

次表面散射的效果强烈依赖于材质的以下光学属性：

- **吸收系数 (Absorption Coefficient - μa):** 描述单位长度内光线被吸收的概率。决定了光线能穿透多深以及颜色如何被过滤（选择性吸收）。吸收系数高的材质（如深色木材、厚皮肤区域）透光性差。
    
- **散射系数 (Scattering Coefficient - μs):** 描述单位长度内光线被散射的概率。决定了光线在内部改变方向的频繁程度。散射系数高的材质（如牛奶、白蜡）光线扩散范围广，看起来更浑浊/柔和。
    
- **散射反照率 (Scattering Albedo - ϖ = μs / (μs + μa)):** 描述单次散射事件中，散射事件相对于吸收事件发生的概率。接近1表示散射主导（光线容易在内部扩散），接近0表示吸收主导（光线很快被吸收）。
    
- **散射相位函数 (Scattering Phase Function - p(θ)):** 描述光线散射方向分布的函数。决定了是前向散射主导还是后向散射主导。
    
- **折射率 (Index of Refraction - n):** 决定光线在表面如何折射进入和射出，影响进入内部的光线总量和方向。
    
- **平均自由程 (Mean Free Path - MFP = 1 / (μs + μa)):** 光线在经历一次吸收或散射事件之前，在材质内部**平均**传播的距离。是描述光线在材质内部扩散范围的关键指标。平均自由程短的材质（如皮肤表皮），光线在很近距离内就被散射或吸收，出射点靠近入射点；平均自由程长的材质（如清澈的蜡、薄玉），光线能传播得更远，出射点可能离入射点较远。
    
- **材质厚度 (Material Thickness):** 光线需要穿越的实际物理距离。在薄区域（如耳朵、花瓣），光线更容易穿透整个厚度，透光感强；在厚区域，光线可能被完全吸收或在深处散射，最终无法射出。
    

**次表面散射模型 (BSSRDF):**

在计算机图形学中，精确描述次表面散射需要比经典的 BRDF (Bidirectional Reflectance Distribution Function - 双向反射分布函数) 更复杂的模型。

- **BRDF:** 只描述光线在**表面同一点**的入射方向和出射方向之间的关系。它隐含假设光线只在表面发生相互作用。
    
- **BSSRDF (Bidirectional Surface Scattering Reflectance Distribution Function):** 这是描述次表面散射的物理模型。它定义了从**表面某一点**入射的光线，对**表面另一点**出射的辐射亮度的贡献。它明确地包含了光线在表面不同点之间传播（即次表面散射）这一核心特征。
