# Blender坐标

## 条件

- Object Mode
- Edit Mode

## 操作

- 坐标系
  - 坐标模式: 编辑区顶部: `Transformation orientation(变换坐标系)`
  - 调整原点(不影响网格): 编辑区右上 `Options(选项)`: `Transform-Affect Only: Origins`
  - 改变旋转中心:
    - 编辑区顶部:`Transform Pivot Point(变换轴心点)`
    - `.`
    - `>`
- 移动坐标
  - 相对移动: Move工具
  - 编辑坐标: 右边栏`Item/Transform` (影响Mesh,无法配置为不影响)
  - [3D光标菜单](Blender3D光标.md): `Selection to Cursor`
