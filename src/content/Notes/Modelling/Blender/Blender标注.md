# Blender标注

Annotate


## 条件

- Object Mode
- Edit Mode
- Sculpt Mode
- Vertex Paint
- Weight Paint
- Texture Paint


## 操作


- Annotate工具
- 设置位置: 视图上方`Placement`
- 擦除: `ctrl` + LMB
- 属性: 右侧面板`Tool`
- 管理: 右侧面板`View/Annotations`

> [!NOTE]
> 3D Cursor: 经[游标](Blender3D光标.md)与视图平行的平面
> View: 与视图相对静止
> Surface: 物体表面
