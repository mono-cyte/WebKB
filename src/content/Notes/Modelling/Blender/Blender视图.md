# Blender视图


## 旋转

- 任意旋转
  - 中键
  - ViewBall
- 视图上旋
  - `Numpad 8`
- 视图下旋
  - `Numpad 2`
- 视图左旋
  - `Numpad 4`
- 视图右旋
  - `Numpad 6`
- 视图旋转半周
  - `Numpad 9`

## 平移

- `shift` + 中键

## 缩放

- 滚轮
- `ctrl` + 中键

## 视图对齐

- 前视图 +X
  - `Numpad 2`
- 左视图 -Y
  - `Numpad 1`
- 顶视图 +Z
  - `Numpad 7`
- 后视图 -X
  - `ctrl` + `Numpad 2`
- 右视图 +Y
  - `ctrl` + `Numpad 1`
- 底视图 -Z
  - `ctrl` + `Numpad 7`
- 对齐轴方向
  - `alt` + 中键

## 物体聚焦

- 聚焦选中目标 & **设置视图旋转中心**
  - `Numpad .`
- 聚焦全部
  - `shift` + `c`

## 网格显示/隐藏

- `shift` + `alt` + `z`

## 透视/正交切换

- `Numpad 5`

## 摄像机视图 Camera

- `Numpad 0`

## 导航视图

- `~`
- 工具栏`View/Navigation/Walk Navigation`

## 局部视图

将 **当前视图** 切换为仅显示选中物体的独立工作区, 非选中物体会被临时隐藏

- `/`
