# 曲率贴图
曲率贴图 是计算机图形学（尤其是PBR工作流）中另一种重要的辅助纹理贴图，它**编码了模型表面几何形状的局部曲率变化信息**。与AO贴图模拟遮挡不同，曲率贴图直接描述了表面的“弯曲程度”和“转折方向”，主要用于增强表面细节的视觉表现，特别是边缘处的磨损、污渍、高光变化等效果。

## 作用

1. **增强边缘细节与磨损效果：**
    
    - **凸起边缘变亮：** 高曲率（尖锐）的**凸起边缘**（如刀刃、硬朗的转角、机械零件的棱边）在曲率贴图中呈现**亮色（白色或接近白色）**。
        
    - **凹陷边缘变暗：** 高曲率（尖锐）的**凹陷边缘**（如深缝、凹槽、雕刻的凹线）在曲率贴图中呈现**暗色（黑色或接近黑色）**。
        
    - **应用：** 这些信息被用来驱动材质效果，例如：
        
        - 让凸起的边缘看起来更**明亮**（模拟磨损掉漆后露出的金属底色或高频高光）。
            
        - 让凹陷的边缘看起来更**暗**（模拟积聚的污垢、油渍、灰尘或阴影）。
            
        - 在边缘处增加**粗糙度/光滑度变化**（磨损的边缘可能更光滑或更粗糙）。
            
        - 在边缘处应用**颜色变化**（如金属锈蚀、油漆剥落）。
            
2. **辅助次表面散射（SSS）：** 在模拟皮肤、蜡、玉石等半透明材质时，光线在较薄（高曲率）的区域（如耳朵边缘、鼻尖、手指关节）穿透得更多，显得更亮更透。曲率贴图可以用来调制SSS的强度和颜色，使这些薄区域的透光效果更自然。
    
3. **微表面细节增强：** 可以与法线贴图或高度贴图配合，在微观层面增强划痕、凹坑等小细节的边缘效果，使其在光照下反应更真实（例如划痕边缘产生微妙的亮边）。
    
4. **分离效果控制：** 为美术师提供了一种独立于基础颜色、法线、粗糙度等贴图之外的、专门用于控制边缘和转折处细节表现的通道。这极大地方便了材质创作和迭代。
    
5. **提升真实感：** 现实世界中的物体，尤其是经过使用或暴露在环境中的物体，其边缘和转折处由于物理接触、磨损、氧化、污染等原因，外观（颜色、亮度、质感）会与平坦区域显著不同。曲率贴图是高效模拟这种“边缘差异化”现象的关键工具。
    

**总结作用：曲率贴图的核心作用是标识出模型表面几何形状发生“尖锐转折”的地方（高曲率区域），并将转折方向（凸起/凹陷）编码为亮度信息，从而驱动各种材质效果在边缘处产生差异化的表现，极大地增强模型的细节感、磨损感和真实感。**

## 实现原理

曲率贴图的实现也分为**生成（烘焙或计算）** 和 **应用（渲染）** 两个阶段。

### 1. 生成/计算原理

核心思想是计算模型表面每个点（顶点或纹理像素）的**局部平均曲率**或其近似值，并根据曲率的大小和符号（凸/凹）映射到灰度值。

- **核心概念 - 曲率：**
    
    - 在微分几何中，曲率描述曲线或曲面偏离直线的程度。
        
    - 对于曲面，通常使用**平均曲率**，它是两个主曲率的平均值。
        
    - 平均曲率**正负号**指示凹凸性：
        
        - **正平均曲率：** 局部表面是**凸**的（像一个球的外表面）。
            
        - **负平均曲率：** 局部表面是**凹**的（像一个球的内部）。
            
    - **曲率绝对值大小：** 表示弯曲的“尖锐”程度。值越大，弯曲越剧烈（边缘越锋利）；值越小，表面越平坦。
        
- **常用计算方法：**
    
    1. **基于顶点或位置数据的计算（烘焙）：**
        
        - 这是最常用的方法，通常在DCC软件（Maya, Blender, ZBrush）或烘焙工具（xNormal, Substance Painter, Marmoset Toolbag）中完成。
            
        - **原理：** 对于表面上的一个点 `P`：
            
            - 计算其相邻顶点（或一定半径内采样点）的平均位置或法线。
                
            - 分析 `P` 点的位置或法线相对于其邻域的变化。
                
        - **常见算法：**
            
            - **顶点法线差值法：** 计算 `P` 点的法线 `N_p` 与其相邻顶点法线 `N_neighbor` 的点积平均值或角度差。点积越小（角度越大），说明法线变化越剧烈，曲率越大。需要区分凸凹（通常通过 `P` 点相对于邻域平均位置的朝向判断）。
                
            - **拉普拉斯算子/平均曲率流法：** 计算顶点 `P` 的拉普拉斯坐标（`P` 的位置减去其邻域顶点的平均位置），该向量的**长度**近似于平均曲率的大小，该向量相对于 `P` 点法线的**方向**（指向模型内部还是外部）指示凹凸性（指向内部为凸，指向外部为凹）。
                
        - **结果映射：** 将计算得到的曲率值（通常是一个带符号的标量）映射到 `[0, 1]` 的灰度范围：
            
            - **高正值（强凸） -> 接近 1.0 (白)**
                
            - **高负值（强凹） -> 接近 0.0 (黑)**
                
            - **接近零（平坦） -> 0.5 (灰)**
                
        - 这种映射使得凸边缘亮、凹边缘暗、平坦区域中性灰。映射函数（如 `sigmoid` 或自定义曲线）常被用来增强对比度或控制效果范围。
            
    2. **基于法线贴图的卷积计算（屏幕空间/实时）：**
        
        - 主要用于实时渲染引擎（如Unreal Engine, Unity）中动态生成曲率近似图。
            
        - **原理：** 利用屏幕空间法线信息 `(N.x, N.y, N.z)`。
            
        - **步骤：**
            
            - 对屏幕空间法线缓冲区的每个像素，取其周围一个小的核（如3x3, 5x5）。
                
            - 在核内计算法线向量的**水平方向导数**（`dN/dx`）和**垂直方向导数**（`dN/dy`）。导数越大，表示法线在屏幕空间变化越快，对应高曲率区域。
                
            - 计算导数的**幅度**（如 `length(float2(dN/dx, dN/dy))`）作为曲率的近似值。
                
            - （可选）区分凹凸较困难，通常只得到一个表示“弯曲强度”的无符号曲率图（类似凹凸边缘都亮）。更复杂的实现可能尝试利用深度信息辅助区分。
                
        - **优点：** 实时，适用于动态物体或变形物体。
            
        - **缺点：** 精度通常低于烘焙方法，区分凹凸性困难，受屏幕分辨率限制，且只能计算可见表面的曲率。
            
- **参数影响：** 烘焙时，关键参数包括：
    
    - **搜索半径/邻域范围：** 决定多大范围内的几何变化影响当前点的曲率计算。半径小，捕捉尖锐细节；半径大，捕捉平缓过渡。
        
    - **强度/对比度：** 控制最终曲率值的缩放和映射范围，影响贴图上亮暗区域的对比度。
        
    - **模糊：** 有时会轻微模糊生成的曲率图，以减少噪点或使效果更柔和。
