# 厚度贴图
厚度贴图（Thickness Map）是计算机图形学中一种专用于模拟**半透明**材质光线透射行为的灰度纹理，尤其在表现[次表面散射](../次表面散射.md)效果时至关重要

---

### **一、核心作用**

1. **驱动次表面散射（SSS）**
    
    - 当光线穿透半透明材质（皮肤、玉石、蜡烛等）时，会在内部散射并从其他位置射出。
        
    - 厚度贴图提供**材质局部的物理厚度数据**，使渲染引擎能动态计算：
        
        - **透光强度**：薄区域透光更强（如耳廓、指尖）。
            
        - **散射颜色**：薄区域因血液/色素呈现红/黄色调（如鼻尖），厚区域保留表面固有色。
            
2. **优化渲染效率**
    
    - 避免为计算真实厚度而增加几何复杂度，用单张纹理低成本存储厚度信息。
        

---

### **二、实现原理**

| **技术环节**   | **说明**                                                                                                                                     |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **贴图格式**   | 单通道灰度图（8位/16位）                                                                                                                             |
| **数值含义**   | - **白色（255）**：极薄（0厚度）  <br>- **黑色（0）**：极厚（最大厚度）  <br>- **灰色**：中间厚度                                                                         |
| **渲染计算逻辑** | 1. 光线击中表面时，采样厚度贴图获取该点厚度值 `T`。  <br>2. 根据材质散射属性与`T`值，计算光线穿透后的衰减与色偏：  <br>- 薄区域：透光率高 → 增强红光散射（皮肤）、边缘泛光（树叶）  <br>- 厚区域：透光率低 → 显示表面漫反射色，减少透光感。 |
| **物理模型参考** | 常用扩散近似方程（Diffusion Approximation）：  <br>`透射光强度 ∝ e^(-σ·T)`  <br>（`σ`为材质散射系数）                                                               |
