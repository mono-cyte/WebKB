# 法线贴图

**法线贴图** 是计算机图形学中最核心的**细节模拟技术**之一，它通过扰动表面法线方向模拟凹凸细节，在不增加模型多边形数量的前提下，大幅提升视觉精度。

法线贴图可以被认为是一种更新更好的[高度贴图](高度贴图.md)

---

### **一、核心作用：光影欺骗**

- **解决的问题**：  
    低多边形模型 (Low-Poly) 因面数限制无法表现细腻表面结构 (如划痕、砖缝、织物褶皱)
    
- **实现原理**：  
    将高模细节的**法线方向信息**烘焙到纹理中，渲染时用该数据**替代真实几何法线**进行光照计算使平滑表面产生凹凸明暗变化

> [!NOTE]
> **本质**：不改变模型形状, 只修改光影反射方向
> 🔍 **对比其他贴图**
> 
> |贴图类型|改变几何|核心作用|
> |---|---|---|
> |**法线贴图**|✖️|伪造凹凸光影|
> |**[厚度贴图](厚度贴图.md)**|✖️|控制光线透射深度|


软件基本上使用点法线
1. 点使用了一个法线, 与周围点通过算法平滑光照可见软边的效果
2. 点使用了多法线, 其夹角范围存在矛盾不进行平滑处理, 从而可见硬边效果

**烘焙**法线贴图 的本质是将高模法线 在像素层面 应用于 低模对应位置

---

### **二、技术原理**

#### **1. 法线方向编码**

- **切线空间（Tangent Space）法线贴图**（最常见）：
    
    - 每个像素的RGB值对应一个**切线空间内的法线向量**：
        
        - `R (Red)` → 切线方向（Tangent）偏移
            
        - `G (Green)` → 副切线方向（Bitangent）偏移
            
        - `B (Blue)` → 法线方向（Normal）强度
            
    - **向量范围**：`(0, 0, 1)`（RGB:128,128,255）表示“无偏移”，实际存储为：
	```
		Mapped_R = (Original_X + 1) * 0.5  
	    Mapped_G = (Original_Y + 1) * 0.5  
	    Mapped_B = (Original_Z + 1) * 0.5  
    
	```

        
- **模型空间（Model Space）法线贴图**：
    
    - RGB直接对应模型坐标系下的法线 (X,Y,Z)
        
    - 缺点：模型旋转时法线方向错误，已逐渐被淘汰。
        

#### **2. 光照计算过程**

1. **顶点着色器**：
    
    - 计算顶点切线（T）、副切线（B）、法线（N）并构建TBN矩阵。
        
2. **片段着色器**：
    
    - 从法线贴图采样 → 解码RGB值为切线空间法向量（范围[-1, 1]）。
        
    - 用TBN矩阵将切线空间法线转换到世界空间。
        
    - 使用转换后的法线计算光照（漫反射、镜面反射）。
        
    
    GL Shader Language 代码示例:
    ```
    vec3 normal = texture(normalMap, texCoords).rgb;
	normal = normalize(normal * 2.0 - 1.0); // 从[0,1]映射到[-1,1]
	normal = normalize(TBN * normal); // 转换到世界空间
	float diffuse = max(dot(normal, lightDir), 0.0);
	```
