# 色彩

人类具有三种[[视锥细胞]], 其中视锥色素的视蛋白分子结构不同决定差异

三种视锥色素分别对 430nm(蓝), 530nm(绿), 560nm(红) 最敏感, 称 三原色

视锥色素的绝对敏感性不同, 所以人眼对光谱的感知是不均匀的

三原色 附近频率的光(及其混合)为 可见光

可见光 任意组合的集合形成 可见光谱

色域 是 可见光谱 的一个子集 (由技术系统, 设备, 程序能够产生的色彩格式)



## 色相 Hue

色相是颜色的 种类

| 颜色    | 波长范围 (nm) | 说明                           |
| ----- | --------- | ---------------------------- |
| **红** | 625–740   | 长波末端，人眼可见红光极限约750nm          |
| **橙** | 590–625   | 红与黄的过渡区，590nm为橙红分界           |
| **黄** | 565–590   | 人眼最敏感区域，575nm为典型黄色           |
| **绿** | 500–565   | 含黄绿(565–550nm)到纯绿(550–500nm) |
| **青** | 485–500   | 绿与蓝的过渡色，490nm为典型青色           |
| **蓝** | 450–485   | 含靛蓝(485–460nm)到纯蓝(460–450nm) |
| **紫** | 380–450   | 短波末端，420nm以下渐变为深紫色           |

### 色相环

由于 视锥色素的感光范围有衔接, 人类对 红, 蓝光 两段离散的波长有连续的感知, 从而能形成色相环
