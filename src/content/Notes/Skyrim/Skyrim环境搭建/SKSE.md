# SKSE


## SKSE Installation

### SKSE Default Installation

1. Copy the `.dll` and `.exe` files to your Skyrim SE directory. This is usually in your Program Files folder under `Steam\SteamApps\common\Skyrim Special Edition\`. 
2. Copy the `.pex` files in `Data\Scripts\` into the `Data\Scripts\` folder of your installation. 
3. copy the `.psc` files in `Data\Scripts\Source\` into the `Data\Scripts\Source\`.

### SKSE as MOD in Mod Organizer 2

1. Create new mod named `SKSE64`
2. Copy `Data\Scripts\` into Mod `SKSE64`
