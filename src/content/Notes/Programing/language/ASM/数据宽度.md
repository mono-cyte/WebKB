# 数据宽度

## 基础

| 单位              | HEX      | DEC        | BIN                              | bits |
| ----------------- | -------- | ---------- | -------------------------------- | ---- |
| 位(bit)           | 1        | 1          | 1                                | 1    |
| 字节(byte)        | FF       | 255        | 11111111                         | 8    |
| 字(word)          | FFFF     | 65535      | 1111111111111111                 | 16   |
| 双字(double word) | FFFFFFFF | 4294967295 | 11111111111111111111111111111111 | 32   |

> 汇编中操作码占用 1 字节, 操作数占用 1~2 字节

## 表示法

示例:

以下为十六进制数 `1000000F` 的等效表示

| HEX           | DEC          | OCT            | BIN                                         |
| ------------- | ------------ | -------------- | ------------------------------------------- |
| `1000 000Fh`  | `268435471d` | `2000000017o`  | `0001 0000 0000 0000 0000 0000 0000 1111b`  |
| `1000 000FH`  |              | `02000000017`  |                                             |
| `0x1000 000F` | `268435471`  | `0o2000000017` | `0b0001 0000 0000 0000 0000 0000 0000 1111` |

## C

| 类型        | 大小(byte)                             |
| ----------- | -------------------------------------- |
| `char`      | 1                                      |
| `short`     | 2                                      |
| `int`       | 4                                      |
| `long`      | 4 (Windows/32位系统) <br>8 (64位Linux) |
| `long long` | 8                                      |
| `__int64`   | 8 (Windows 定义, 等效 `long long`)     |
| `float`     | 4                                      |
| `double`    | 8                                      |
