# 字节序
## 小端序

**低位**字节存入**低地址**，**高位**字节存入**高地址**[^默认增长顺序]

[^默认增长顺序]:默认增长顺序: 左低右高, 上低下高

| 地址    | 数值     |
| ----- | ------ |
| $x$   | `0x78` |
| $x+1$ | `0x56` |
| $x+2$ | `0x34` |
| $x+3$ | `0x12` |

示例:

| 数据           | 寄存器/堆栈视图      | 内存视图          |
| ------------ | ------------- | ------------- |
| `0x12345678` | `12 34 56 78` | `78 56 34 12` |
| `0x00000064` | `00 00 00 64` | `64 00 00 00` |
> **寄存器/堆栈视图** 为 逻辑顺序, 人类可读
> **内存视图** 为 默认增长顺序, 左低位右高位

## 大端序

- 日常数字写法
- 网络字节序

**低位**字节存入**高地址**，**高位**字节存入**低地址**
## 字符串

字符串数据不受字节序影响，始终按书写顺序从低地址到高地址连续存储

示例字符串 "Hello" 

| 内存地址      | 存储的字节值 | ASCII 字符 |
| --------- | ------ | -------- |
| $x$       | `0x48` | 'H'      |
| $x+1$     | `0x65` | 'e'      |
| $x+2$     | `0x6C` | 'l'      |
| $x+3$     | `0x6C` | 'l'      |
| **$x+4$** | `0x6F` | 'o'      |
