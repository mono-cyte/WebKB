# XDBG 指南

## 常用功能

### 快捷键

| 功能    | 快捷键                 | 说明                   |
| ----- | ------------------- | -------------------- |
| 重新运行  | `s`,<br>`ctrl`+`F2` |                      |
| 结束    | `c`,<br>`alt`+`F2`  |                      |
| 运行    | `r`,<br>`F9`        |                      |
| 暂停    | `p`,<br>`F12`       |                      |
| 步进    | `i`,<br>`F7`        | 逐行执行 (进入被调用函数内部, 内层) |
| 步过    | `o`,<br>`F8`        | 逐行执行 (函数调用视为一行)      |
| 运行到返回 | `x`,<br>`ctrl`+`F9` | 执行到函数结束, 返回调用处 (外层)  |
| 回退    | `-`                 |                      |
| 前进    | `+`                 | 与 回退 结合使用            |
