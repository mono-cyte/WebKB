# 光栅化


Raster == screen (in German) -> Rasterize == drawing onto the screen


光栅化是将几何图元（点, 线, 三角形）转换为屏幕像素的过程

#### 光栅化流程

1. **图元装配**：将顶点组装成图元（点、线、三角形）
2. **裁剪**：移除视锥体外的图元部分
3. **透视除法**：将齐次坐标转换为标准化设备坐标
4. **视口变换**：将标准化坐标转换为屏幕坐标
5. **扫描转换**：确定图元覆盖的像素
6. **插值**：为每个像素插值顶点属性

#### 光栅化设置



#### 光栅化特性：

1. **填充模式**：
    
    - `D3D11_FILL_SOLID`：实体填充
    - `D3D11_FILL_WIREFRAME`：线框模式
2. **剔除模式**：
    
    - `D3D11_CULL_NONE`：不剔除
    - `D3D11_CULL_FRONT`：剔除正面
    - `D3D11_CULL_BACK`：剔除背面
3. **多重采样**：用于抗锯齿处理
