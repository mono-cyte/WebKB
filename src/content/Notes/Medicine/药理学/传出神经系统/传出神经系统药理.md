# 传出神经系统药理

传出神经系统药物的药理作用为 拟似/拮抗 传出神经系统的功能

## 胆碱能神经兴奋

副交感神经+运动神经 兴奋

1. 心 ($M_2$) : **减压节能**
	1. 肌力--
	2. 频率--
	3. 传导性--
2. 平滑肌 ($M_3$)
	1. 支气管++ : **呼吸下降/睡眠状态**
	2. 胃肠道++ : **促进消化/排遗**
	3. 膀胱++ : **促进排尿**
3. 眼 ($M_3$) : **缩瞳视近物**
	1. 虹膜环状肌++
	2. 睫状肌++
4. 腺体 ($M_3$)
	1. 汗腺++
	2. 消化腺++ **促进消化**
5. 骨骼肌++($N_2$) : **促进运动**
