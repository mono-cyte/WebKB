# 乙酰胆碱
## 特点


1. 内源性神经递质
2. 不稳定，易被胆碱酯酶 AChE 迅速水解
3. 选择性差, 作用广泛，副作用多
4. 不易透过血脑屏障
5. 目前仅作为工具药使用，无临床实用价值

## 靶点

1. M(毒蕈碱型)胆碱受体
2. N(烟碱)胆碱受体

## 作用

### 心血管

1. 负性肌力：心房肌上$M_2$ 使心房肌收缩力减弱
2. 负性传导：作用于房室结$M_2$ ，减慢传导
3. 负性心率：激动窦房结上$M_2$ ，抑制AC活性，引起K+通道开放，大量的K+外流，细胞膜电位超极化，使窦房结舒张期自动除极延缓，自律性降低，心率减慢
4. 舒张血管：ACh通过激动血管内皮$M_3$，导致内皮舒张因子NO释放，使血管扩张


### 胃肠道

ACh ->  胃肠道平滑肌$M_3$  [[磷脂酶 C|PLC]] -> [[三磷酸肌醇|IP3]], [[二酰甘油|DAG]] 增多 -> $Ca^{2+}$ 增多

维持胃肠平滑肌张力、蠕动，引起恶心、嗳气、腹痛及排便等

### 泌尿道

膀胱壁逼尿肌收缩

膀胱三角区和括约肌舒张

### 其他
