# 糖皮质激素


下丘脑--腺垂体--肾上腺皮质轴


生理情况下所分泌的GCS主要影响物质代谢的过程

升糖解蛋分脂保钠

1. 糖
	促进糖原异生（gluconeogenesis）；
	减慢葡萄糖分解为CO2的氧化过程；
	减少外周组织对葡萄糖的摄取和利用
2. 蛋白质
	合成减少、分解增加: 负氮平衡，从而产生肌肉萎缩、皮肤变薄、生长发育迟缓、伤口难愈
3. 脂肪代谢
	1. 脂肪合成减少、分解增加: 诱发酮症酸中毒
	2. 脂肪再分布: 向心性肥胖、满月脸
4. 水、电解质代谢
	1. 留钠排钾: 水钠潴留、低血钾、高血压
	2. 增加钙、磷排泄: 骨质疏松。

超生理剂量的GCS则有抗炎、免疫抑制、抗休克、抗毒、血液系统作用等药理作用

糖皮质激素抗炎作用的基本机制是基因效应

允许作用: 糖皮质激素对某些组织细胞虽无直接作用，但可为其他激素发挥作用创造条件

抗炎作用

免疫抑制和抗过敏作用: 小剂量即可对抑制细胞免疫，大剂量时明显抑制体液免疫

抗内毒素作用

抗休克作用（升压）

退热作用

四抗
1. 抗炎
2. 抗免疫
3. 抗内毒素
4. 抗休克

五影响
1. 血液及造血系统
2. 消化系统
3. 中枢
4. 心血管系统
5. 骨骼
