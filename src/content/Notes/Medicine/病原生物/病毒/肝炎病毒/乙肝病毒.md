# 乙肝病毒


## 形态

1. 大球形颗粒(Dane颗粒)
	- 包膜&含DNA核衣壳(20面体) 病毒颗粒
	- 游离核衣壳 仅在肝细胞核可见
	- 浓度在急性肝炎潜伏期后期最高, 起病后迅速下降
	- 表面含有 HBsAg
	- 可认为 Dane颗粒 即完整 HBV
2. 小球形颗粒
	- HBV 感染后血液最多见, 游离
	- 主要成分为 HBsAg
	- 可能为合成过剩的HBsAg装配形成
3. 管形颗粒
	- 聚合的小球形颗粒


## 抗原组成

1. HBsAg 表面抗原
2. HBcAg 核心抗原
	1. 对HBV无抑制作用
3. HBeAg e抗原
	1. 类似DNA多聚酶
	2. 反映HBV复制&传染性
4. HBxAg x抗原

## 临床检查

| HBsAg | HBeAg | 抗 HBs | 抗 HBe | 抗 HBc IgM | 抗 HBc IgG | 分析              |
| ----- | ----- | ----- | ----- | --------- | --------- | --------------- |
| +     | +     | -     | -     | +         | -         | **大三阳**: 急性/慢性  |
| +     | +     | -     | -     | +         | +         | 急性/慢性/无症状       |
| +     | -     | -     | +     | -         | +         | **小三阳**: 急性->恢复 |
| +     | -     | -     | -     | -         | -         | 无症状             |
| -     | -     | +     | +     | -         | +         | 恢复期             |
| -     | -     | +     | -     | -         | -         | 曾接种/感染, 已恢复     |
| -     | -     | -     | -     | -         | +         | 曾感染             |

前置: 抗原和相应抗体不会同时阳性

HBsAg + 表明处于感染状态
HBeAg + 表明病毒活跃
抗 HBc + 表明 无效抵抗力
抗 HBe + 表明 中效抵抗力
抗 HBs + 表明 高效抵抗力
