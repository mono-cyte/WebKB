# 发热

正常人在[[体温调节中枢]]调控下，通过神经，体液因素使产热和散热动态平衡，维持人体体温在相对恒定范围


| 部位  | 温度(°C)       | 均值(°C) |
| --- | ------------ | ------ |
| 口腔  | 36.3~37.2    |        |
| 直肠  | 口腔 + 0.3~0.5 |        |
| 腋窝  | 口腔 - 0.2~0.4 |        |
| 核心  | 36.9~37.9    | 37     |

对于正常体温范围 $T$, 实际体温 $t$, 定义 $t - max(T) \geq 0.5$ 为 发热


## 发热机制

体温调节由 产热，散热 环节控制，至少一个环节异常导致发热
