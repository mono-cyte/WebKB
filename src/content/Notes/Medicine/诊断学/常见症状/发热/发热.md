# 发热

正常人在[[体温调节中枢]]调控下，通过神经，体液因素使产热和散热动态平衡，维持人体体温在相对恒定范围


| 部位  | 温度           | 均值  |
| --- | ------------ | --- |
| 口腔  | 36.3~37.2    |     |
| 直肠  | 口腔 + 0.3~0.5 |     |
| 腋窝  | 口腔 - 0.2~0.4 |     |
| 核心  | 36.9~37.9    | 37  |

## 生理性影响因素
### 昼夜周期

2~5.a.m 最低
2~5.p.m 最高
### 年龄

儿童>青壮年>老年
