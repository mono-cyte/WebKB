# 腹部分区


## 腹部体表特征

| name  | desc |
| ----- | ---- |

## 四区划分

以脐为中点，沿**矢状面**，**水平面**划分四区:
	$\{\text{左},\text{右}\} \times \{\text{上},\text{下}\}$

## 九区划分

以肋弓下缘最低点(2)，髂前上棘(2)，沿**矢状面**，**水平面**划分九区:


| part | content                                            |
| ---- | -------------------------------------------------- |
| 右上腹部 | **肝**(右叶)<br>**胆囊**<br>右肾                          |
| 右侧腹部 | 升结肠<br>空肠                                          |
| 右下腹部 | **盲肠**<br>**阑尾**<br>空肠下端<br>卵巢<br>输卵管<br>精索<br>淋巴结 |
| 左上腹部 | 胃<br>**脾**<br>胰尾<br>左肾上部                           |
| 左侧腹部 | 降结肠<br>空肠<br>回肠<br>左肾下部                            |
| 左下腹部 | 乙状结肠<br>卵巢<br>输卵管<br>精索<br>淋巴结                     |
| 腹上区  | 肝(左叶)<br>胃幽门<br>十二指肠<br>胰头<br>腹主动脉                 |
| 脐部   | 十二指肠下端<br>空回肠<br>输尿管<br>腹主动脉<br>大网膜<br>肠系膜<br>淋巴结  |
| 下腹部  | 回肠<br>输尿管<br>乙状结肠                                  |
