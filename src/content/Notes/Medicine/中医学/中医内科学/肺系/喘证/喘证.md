# 喘证

喘证是以**呼吸困难**，短促急迫，甚则张口抬肩，鼻翼扇动，不能平卧为主症的疾病


| 程度  |     轻     |       重        |              严重               |
| --- | :-------: | :------------: | :---------------------------: |
| 表现  | 呼吸困难，不能平卧 | 喘息不已，张口抬肩，鼻翼扇动 | 喘持续不解，烦躁不安，面青唇紫，肢冷，汗出如珠，脉浮大无根 |


## 现代诊断

- 肺炎
- 慢性阻塞性肺病
- 肺源性心脏病
- 心源性哮喘

## 病因

- 外邪
- 饮食
- 情志
- 劳欲

## 病机

肺气上逆，宣降失职
## 治法

实喘：祛邪利气

| 因素  | 原则   |
| --- | ---- |
| 寒   | 温化宣肺 |
| 热   | 清化肃肺 |
| 痰   | 化痰理气 |
| 气   | 化痰理气 |

虚喘：培补摄纳
