# 哮病

- 哮病是以**喉中哮鸣有声**，**呼吸困难**，甚则喘息不能平卧的**反复发作性**疾病

> [!NOTION]
> 哮必兼喘，喘未必兼哮

|     | 发作期     | 缓解期    |
| --- | ------- | ------ |
| 声   | 气粗声高    | 气怯声低   |
| 息   | 深长，呼出则快 | 短促，吸不利 |
| 脉   | 有力      | 沉细数    |

## 现代诊断

- 支气管哮喘
- 喘息性支气管炎
- 嗜酸性粒细胞增多症

或其它急性肺部过敏疾病引起的哮喘



## 病因

- 外邪
- 饮食
- 情志
- 体虚

## 病机

**伏痰**在肺，哮病病根

脏腑功能失调，肺不布散，脾不运化，肾不蒸化，津液凝聚成痰，伏于肺
## 治法

1. 未发宜扶正: 缓解期，治本，补益脾肺肾
2. 已发用攻邪：发作期，治标，祛痰利气
