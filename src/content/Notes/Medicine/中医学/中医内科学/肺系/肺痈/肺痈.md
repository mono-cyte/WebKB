# 肺痈



**肺痈**[^肺痈]是以咳嗽，胸痛，发热，**咳吐腥臭浓痰**甚则脓血相兼为主症的疾病

[^肺痈]: [[../../../金匮要略/肺痿肺痈咳嗽上气病/肺痈|肺痈]]
## 现代诊断

- 支气管扩张合并感染
- 肺脓肿
- 化脓性肺炎
## 病因

- 外邪：风热|风寒郁闭
- 内邪：痰热
- 内外邪

## 病机

热伤肺气，蒸液成痰，热壅血瘀，血败肉腐

## 治法

原则：祛邪
1. 清热解毒
2. 化瘀排脓

| 阶段  | 脓未成  | 脓已成  |
| --- | ---- | ---- |
| 治法  | 清肺消痈 | 排脓解毒 |


| 阶段  | 初期   | 成痈期          | 溃脓期  | 恢复期          |
| --- | ---- | ------------ | ---- | ------------ |
| 治法  | 清肺散邪 | 清热解毒<br>化瘀消痈 | 排脓解毒 | 养阴益气<br>扶正祛邪 |

> [!NOTION]
