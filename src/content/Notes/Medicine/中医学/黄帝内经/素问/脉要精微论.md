## 核心内容

### 诊法常以平旦

诊法常以平旦，阴气未动，阳气未散，饮食未进，经脉未盛，络脉调匀，气血未乱故乃可诊有过之脉

此时自然界处于阴阳交接之时，人体阴阳平和，处于宁静状态，体内外的环境都比较安静，所以反映的疾病是真实的，因此诊出的脉象可以判断疾病的轻重和预后的吉凶

诊察疾病时需要在体内外环境都比较安静的状况下进行，所以在平旦以外的时候诊病诊脉，必须避免饮食、运动、情志等干扰因素，从而能比较准确地获得信息

### 精明五色诊病

#### 五色

夫精明五色者，气之华也 (五脏精气)


| 色   | 欲    | 不欲       |
| --- | ---- | -------- |
| 赤   | 白裹朱  | 赭        |
| 白   | 鹅羽   | 盐        |
| 青   | 苍壁之泽 | 蓝 (染料草名) |
| 黄   | 罗裹雄黄 | 黄土       |
| 黑   | 重漆色  | 地苍       |

五色精微象(真脏色)见矣，其寿不久也

#### 精明

夫精明者，所以视万物、别白黑、审短长。

以长为短、以白为黑 (长短不分、黑白颠倒)，如是则精衰矣



### 五脏失守失强

#### 失守

五藏者，中之守也 (内守精气)

| 病                 | 证    | 解     |
| ----------------- | ---- | ----- |
| 中盛藏满，气胜伤恐者，声如从室中言 | 中气之湿 | 脾肺肾失守 |
| 言而微，终日乃复言者        | 夺气   | 肺失守   |
| 衣被不敛，言语善恶不避亲疏者    | 神明之乱 | 心失守   |
| (幽,阑,魄门)门户不约(束)   | 仓廪不藏 | 脾失守   |
| 水泉不止 (遗尿失禁)       | 膀胱不藏 | 肾失守   |

得守者生，失守者死

#### 失强

夫五藏者，身之强也


| 部位  | 地位   | 表现            |
| --- | ---- | ------------- |
| 头   | 精明之府 | 头倾视深，精神将夺     |
| 背   | 胸中之府 | 背曲肩垂，府将坏      |
| 腰   | 肾之府  | 转摇不能，肾将惫      |
| 膝   | 筋之府  | 屈伸不能，行则偻附，筋将惫 |
| 骨   | 髓之府  | 不能久立，行则振掉，骨将惫 |

得强则生，失强则死
