## 核心内容

### 热病

#### 起病

今夫热病者，皆伤寒之类也 (泛指致病因素)

巨阳(太阳)者，诸阳之属也。其脉连于风府，故为诸阳主气也 (起病部位)

#### 分类

人之伤于寒也，则为病热，热虽甚不死，其两感于寒而病者，必不免于死

| 伤寒热病    | 预后    | 传变  |
| ------- | ----- | --- |
| 非两感于寒而病 | 热虽甚不死 | 顺   |
| 两感于寒而病  | 必不免于死 | 逆   |

#### 传变

| 时间  | 六经传变 | 证候        |
| --- | ---- | --------- |
| 一日  | 巨阳受之 | 头项痛腰脊强    |
| 二日  | 阳明受之 | 身热目疼鼻干不得卧 |
| 三日  | 少阳受之 | 胸胁痛而耳聋    |
| 四日  | 太阴受之 | 腹满而嗌干     |
| 五日  | 少阴受之 | 口燥舌干而渴    |
| 六日  | 厥阴受之 | 烦满而囊缩     |

三阴三阳，五脏六腑皆受病，荣卫不行，五脏不通，则死矣

##### 非两感于寒而病

| 时间  | 六经传变 | 证候                |
| --- | ---- | ----------------- |
| 七日  | 巨阳病衰 | 头痛少愈              |
| 八日  | 阳明病衰 | 身热少愈              |
| 九日  | 少阳病衰 | 耳聋微闻              |
| 十日  | 太阴病衰 | 腹减如故，则思饮食         |
| 十一日 | 少阴病衰 | 渴止不满，舌干已而嚏        |
| 十二日 | 厥阴病衰 | 囊纵，少腹微下，大气皆去，病日已矣 |

##### 两感于寒而病

| 时间  | 六经传变    | 证候              |
| --- | ------- | --------------- |
| 一日  | 巨阳与少阴俱病 | 头痛、口干而烦满        |
| 二日  | 阳明与太阴俱病 | 腹满, 身热, 不欲食, 谵言 |
| 三日  | 少阳与厥阴俱病 | 耳聋囊缩而厥          |
| 四日  |         | 水浆不入, 不知人       |
| 五日  |         | 水浆不入, 不知人       |
| 六日  |         | 水浆不入, 不知人, 死    |

### 六经分证

### 热病汗泄大法

其未满三日者，可汗而已；其满三日者，可泄而已 (针刺)

### 热病遗复

1. 诸遗者，热甚而强食之
2. 病热少愈，食肉则复，多食则遗

| 病    | 因   | 理              |
| ---- | --- | -------------- |
| 遗(留) | 多食  | 余热与谷食之热羁留      |
| 复(发) | 食肉  | 肉类甘肥，生湿敛邪，化火助热 |


### 暑病与温病

冬中寒邪不即病，至春变温病，至夏变暑病
