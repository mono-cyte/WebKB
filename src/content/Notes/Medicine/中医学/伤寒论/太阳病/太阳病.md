# 太阳病

## 太阳病脉证

太阳之为病，脉浮，头项僵痛而恶寒

## 太阳病分类

### 中风

太阳病，发热，恶风，脉缓者，名为中风

| 部位  | 额外特征 |
| --- | ---- |
| 体温  | 发热   |
| 体感  | 恶风   |
| 脉   | 缓    |

### 伤寒

太阳病，或已发热，或未发热，必恶寒，体痛，呕逆，脉阴阳俱紧者，名为伤寒

| 部位  | 额外特征    |
| --- | ------- |
| 体温  | 发热\|不发热 |
| 体感  | 恶风，体痛   |
| 脉   | 紧       |
| 气   | 呕逆      |

### 温病

太阳病，发热而渴，不恶寒者为温病

若发汗已，身灼热者，名风温。风温为病，脉阴阳俱浮，自汗出，身重，多眠睡，鼻息必鼾，语言难出
若被下者，小便不利，直视失溲
若被火者，微发黄色，剧则如惊痫，时瘛疭，若火熏之
一逆尚引日，再逆促命期

| 部位  | 额外特征     |
| --- | -------- |
| 体温  | 高热       |
| 体感  | 不恶寒，身重   |
| 神志  | 多眠(鼾)，难言 |

## 太阳病原发

病有发热恶寒者，发于阳也；无热恶寒者，发于阴也
发于阳，七日愈
发于阴，六日愈
以阳数七，阴数六故也

## 太阳病传变

伤寒一日，太阳受之，脉若静者，为不传；颇欲吐，若躁烦，脉数急者，为传也

伤寒二三日，阳明，少阳证不现者，为不传也

太阳病，头痛至七日以上自愈者，以行其经尽故也
若欲作再经者，针足阳明，使经不传则愈
