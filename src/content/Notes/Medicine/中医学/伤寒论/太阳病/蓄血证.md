# 蓄血证


| 证      | 病机   | 治法       | 特征   |
| ------ | ---- | -------- | ---- |
|        |      |          |      |
| 桃核承气汤证 | 热重瘀轻 | 先表后里泻热逐瘀 | 燥屎内结 |
| 抵当汤证   | 瘀重热轻 | 先里后表破结逐瘀 | 血分瘀结 |
| 抵当丸    | 结深势缓 |          |      |

太阳病不解，热结膀胱，其人如狂，血自下，下者愈
其外不解者，尚未可攻，当先解其外；外解已，乃可攻之，宜[桃核承气汤](../../方剂学/方剂/理血剂/活血化瘀/桃核承气汤.md)

太阳病六七日，表证仍在，脉微而沉，反不结胸，其人发狂者，以热在下焦，少腹当硬满，小便自利者，下血乃愈
所以然者，以太阳随经，瘀热在里故也，[抵当汤](../../方剂学/方剂/理血剂/活血化瘀/抵当汤.md)主之

太阳病身黄，脉沉结，少腹硬，小便不利，为无血(证)也
小便自利，其人如狂者，血证谛也，[抵当汤](../../方剂学/方剂/理血剂/活血化瘀/抵当汤.md)主之


> 血瘀发黄：阴黄，小便自利，营气不输致
> 湿热发黄，阳黄，小便短赤不利


伤寒有热，少腹满，应小便不利，今反利者，为有血也，当下之，不可余药，宜[[抵当丸]]
