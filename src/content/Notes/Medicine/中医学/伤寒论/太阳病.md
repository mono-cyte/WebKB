# 太阳病

## 太阳病共同特征

太阳之为病，脉浮，头项僵痛而恶寒

## 中风

太阳病，发热，恶风，脉缓者，名为中风

| 部位  | 额外特征 |
| --- | ---- |
| 体温  | 发热   |
| 体感  | 恶风   |
| 脉   | 缓    |

## 伤寒

太阳病，或已发热，或未发热，必恶寒，体痛，呕逆，脉阴阳俱紧者，名为伤寒

| 部位  | 额外特征    |
| --- | ------- |
| 体温  | 发热\|不发热 |
| 体感  | 恶风，体痛   |
| 脉   | 紧       |
| 气   | 呕逆      |

## 温病

太阳病，发热而渴，不恶寒者为温病

若发汗已，身灼热者，名风温。风温为病，脉阴阳俱浮，自汗出，身重，多眠睡，鼻息必鼾，语言难出
若被下者，小便不利，直视失溲
