# 阴离子间隙
阴离子间隙指血浆中**未测定**的 阴离子量 undetermined anion (UA) 与 阳离子量 undetermined cation (UC) 的差值

$AG = UA - UC$

$\text{血浆总阴离子} = Cl^- + HCO_3^- + UA$

$\text{血浆总阳离子} = Na^+ + UC$

## UA
1. 蛋白质阴离子 $Pr^-$
2. 有机酸根离子
3. $HPO_4^{2-}$
4. $SO_4^{2-}$

## UC
1. $K^+$
2. $Ca^{2+}$
3. $Mg^{2+}$
