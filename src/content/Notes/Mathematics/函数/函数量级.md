# 函数量级

函数在无穷远处的增长界限
## 最大阶

**定义：** 函数 $f(n)$ 的阶至多为 $g(n)$，记作 $f(n)=O(g(n))$

当且仅当：$\exists c>0, \exists n_{0} \geq 0, \forall n \geq n_{0}$ : $|f(n)| \leq c|g(n)|$


## 最小阶

**定义：** 函数 $f(n)$ 的阶至少为 $g(n)$，记作 $f(n)=\Omega(g(n))$

当且仅当：$\exists c>0, \exists n_{0} \geq 0, \forall n \geq n_{0}$ : $|f(n)| \geq c|g(n)|$

## 阶等价
$f$ 和 $g$ 的阶等价: 记为 $f(n) = \Theta(g(n))$

当且仅当：$\exists c_{1},c_{2}$ : $c_{1}|g(n)| \leq |f(n)| \leq c_{2}|g(n)|$
