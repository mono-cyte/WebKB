# 拉格朗日乘数法

寻找变量受一个或多个条件所限制的 多元函数 的 极值 的方法

例:

多元函数 $f(x, y, \cdots, n)$
约束方程 $\psi = 0, \omega=0, \cdots$

构造 **拉格朗日函数** $L(x,y,\cdots,n,\lambda,\mu) = f + \lambda\psi + \mu\omega$ 

> 混合约束, 仅当满足约束时, $L = f$, 解在 $f$ 中

解方程组:
$$
\begin{cases}
	L'_x = 0 \\
	L'_y = 0 \\
	\vdots \\
	L'_n = 0 \\
	L'_{\lambda} = 0 \\
	L'_{\mu} = 0
\end{cases}
$$

其中 	$L'_{\lambda} = 0,L'_{\mu} = 0$ 与 **约束方程** 等效, 确保解在 $f$

解得 极值点 必然包含约束信息 且 位于 $f$
